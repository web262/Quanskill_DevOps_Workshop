Workshop

From learning DevOps tools to building AI-assisted engineering workflows.

This workshop converts the larger AI in DevOps course into a focused, high-impact 2-week training experience suitable for student cohorts, working professionals, and corporate teams.

Executive Summary

QuanSkill can position this 2-week workshop as a practical bridge between DevOps, cloud-native engineering, and applied AI. Participants will not only understand CI/CD, Docker, Kubernetes, observability, and incident response, but also learn how AI can assist with log analysis, pipeline debugging, runbook generation, security checks, and infrastructure documentation through repeated practice and a final project demo.

Why This Workshop

DevOps is becoming AI-assisted, but engineers still need control.

The workshop emphasizes human-approved automation. AI is used as a co-pilot for analysis, documentation, summaries, and recommendations, not as an unsafe autonomous system executing production commands.

🧠

AI makes DevOps faster

Learners practice using AI to summarize failed builds, explain container errors, generate checklists, and convert noisy logs into readable incident notes.

⚙️

DevOps makes AI usable

The workshop shows how modern AI applications require containers, CI/CD, secrets management, monitoring, deployment discipline, and rollback strategies.

🛡️

Safety remains central

Every AI recommendation is wrapped with review steps, secure scanning, approval gates, and clear limits so learners understand responsible automation.

Hands-on Labs

Labs that make the workshop feel real, not theoretical.

Each lab is designed for repeated practice across two weeks and is meaningful enough to become part of the learner's portfolio.

01

AI Pipeline Failure Explainer

Run a failing GitHub Actions workflow, collect the logs, and generate a structured diagnosis: symptom, likely cause, fix, and prevention rule.

02

GitHub Workflow Hardening

Add checks, branch discipline, environment variables, and a clean workflow structure suitable for student or junior engineer portfolios.

03

Dockerfile Review Assistant

Review a Dockerfile for image size, caching, user permissions, exposed ports, dependency risk, and production-readiness.

04

Container Security Scan

Use Trivy to scan a container image, interpret findings, and create a human-readable remediation note with AI support.

05

Kubernetes Event Translator

Convert pod events, crash logs, and rollout status into beginner-friendly explanations and safe troubleshooting steps.

06

Deployment Rollback Drill

Simulate a bad deployment, inspect status, identify the failure point, and prepare a controlled rollback checklist.

07

Log Anomaly Detector

Use Python to parse log patterns, detect spikes, classify severity, and produce an AI-written incident summary.

08

Observability Dashboard Notes

Map metrics, logs, and alert signals into a simple dashboard plan and explain what each signal means for reliability.

09

Secure Automation Gate

Design a human approval step before any risky command and add security scanning with Trivy, Gitleaks, or Semgrep.

10

README + Architecture Demo

Turn the technical build into a clean GitHub README with architecture diagram, setup steps, screenshots, demo explanation, and final presentation flow.
